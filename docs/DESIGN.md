# 界面设计与取舍

需求文档 `实时聆听.md` 保持不变。本文记录实现时按 Windows 11 的交互习惯做的调整，以及需求文档「首批待定事项」的决定。

## 浮条

参照 Win+H 语音输入面板：顶部是拖动柄和关闭按钮，中间一行左边是快速设置（齿轮），正中是麦克风，右边是帮助（问号）。

| 调整 | 原因 |
| --- | --- |
| 点击浮条不会抢走焦点（窗口不激活） | 听写的目标是用户正在输入的文本框，焦点一旦移到浮条，文字就写错地方 |
| 快速设置和帮助在浮条内向上展开，不弹出独立窗口 | 弹出窗口会抢焦点；向上展开不遮挡下方的输入框 |
| 快速设置只放最常改的四项：显示实时文字、写入方式、持续听写结束后、实时字幕；其余放「全部设置」 | 浮条保持紧凑 |
| 帮助只列三条快捷键和「更改快捷键」入口 | 用法说明压缩到一屏 |
| 状态行一句话说明当前该做什么，例如「按住 右 Ctrl 说话」「正在听，松开结束」 | 不需要另看说明 |
| 关闭按钮只隐藏浮条；第一次关闭时托盘提示「实时聆听仍在运行」 | 符合托盘常驻应用的习惯，快捷键照常可用 |
| 不固定时，浮条在听写开始时出现，结束 1.5 秒后隐藏 | 平时不占屏幕 |
| 位置记住；窗口在屏幕下半部时，展开或收起保持底边不动 | 浮条不跳动 |

### 状态动画

| 状态 | 表现 |
| --- | --- |
| 空闲 | 静止的麦克风 |
| 连接中 | 缓慢呼吸的光圈 |
| 收音中 | 光圈随音量缩放（心跳感），强调色 |
| 处理中（收尾） | 环形进度 |
| 失败 | 状态行显示原因，例如「无法连接识别服务」 |

浮条隐藏后停止所有动画。系统关闭了动画效果时只保留颜色变化。

## 字幕

| 调整 | 原因 |
| --- | --- |
| 独立浮层，默认在屏幕底部居中，宽度为屏幕的 60% | 与常见视频字幕位置一致 |
| 与浮条重叠时，字幕自动放在浮条上方 | 两者都在底部时互不遮挡 |
| 鼠标移上去才出现关闭按钮 | 平时只显示文字 |
| 可选「点击穿透」 | 字幕盖在视频或会议窗口上时不挡操作 |
| 没有声音时显示「等待声音…」 | 让用户知道字幕已开启 |
| 出错信息显示 6 秒后消失 | 不长期遮挡 |

## 设置窗口

- Mica 背景、左侧导航，共七页：听写、字幕、随手记、快捷键、外观、服务、通用。
- 每项一张卡片，标题加一句说明；改动立即生效并自动保存，没有「应用」按钮。
- 外观页有实时预览，浮条、字幕、卡片分别设置，可一键恢复默认。卡片可选「所有卡片（统一外观）」或某一张卡片；单独设置的外观存在这张卡片里，「使用统一外观」或「全部改用统一外观」把它们改回去。
- 快捷键页按一下「录制」后直接按组合键，按 Esc 取消；冲突时当场提示。
- 服务页的每个识别服务都有「检查」按钮，显示能否使用和支持的能力。

## 随手记

| 调整 | 原因 |
| --- | --- |
| 放在设置窗口里，位于「字幕」和「快捷键」之间 | 不再多开一个窗口 |
| 桌面卡片不置顶、点击会获得焦点 | 卡片要能直接改文字；置顶会挡住正在用的窗口 |
| 卡片拖动标题行移动；× 只从桌面隐藏，归档才收起 | 隐藏和归档分开，误点也不会丢 |
| 删除卡片要再次确认，并提示可以改用归档 | 删除无法恢复 |
| 右击卡片「自定义外观…」打开外观页并选中这张卡片；改动先在卡片上预览，停顿约 0.3 秒后保存 | 拖动滑块时不必每一步都写盘 |

## 用词

界面文字尽量短，用动作说明代替术语：

| 需求文档 | 界面 |
| --- | --- |
| 边说边写入稳定片段 | 稳定写入 |
| 临时识别结果写入后原位修正 | 实时修正 |
| 只结束听写 | 只结束 |
| 最后一段写入后执行原按键或点击 | 结束并执行按键 |
| 显示实时字幕 / 仅显示状态动画 | 显示实时文字（开关） |

## 待定事项的决定

1. **Rust 与 WinUI 3 的接入**：界面用 C# WinUI 3，Rust 核心编成 DLL，通过 C 接口传 JSON。理由见 [ADR 0002](adr/0002-winui3-shell-rust-core.md)。浮条不抢焦点、透明背景、托盘、单实例和开机启动已在本机验证。
2. **写入策略**：默认「稳定写入」，「实时修正」可选。
   - 稳定写入从不删除已写的文字，用户同时打字、移动光标或切换窗口时不会误删。
   - 实测豆包的确定文字在一句话结束时才到达，所以稳定写入按句写入；想要更快看到文字可开启浮条的「显示实时文字」，或改用实时修正。
   - 实时修正依赖退格修改已写内容，光标被移走时可能改错位置，因此不作为默认。
3. **字幕音源与并行规则**：
   - 字幕默认用电脑声音，也可选麦克风或混合。
   - 听写和字幕同时开启、字幕音源又是麦克风时，只做一次识别，字幕直接显示听写的文字。
   - 不保存录音。字幕只在内存中保留最近几行，关闭后清空，不保存。
4～6. **对话记录的保留、说话人、摘要与待办**：对话记录、说话人区分和摘要已移除，这几项不再适用，见 [ADR 0003](adr/0003-remove-translation-records-speakers.md)。
7. **随手记归类**：以「待办」「记得」「提醒我」「别忘了」「todo」「remind me to」等开头的成为待办，开头的提示词会去掉；其余是随手记。可在列表中改类型。
8. **卡片重启后是否恢复**：恢复。卡片、完成和归档状态、是否显示在桌面、位置以及单独设置的外观都保存在 `cards.json`，下次启动按原位置显示。
