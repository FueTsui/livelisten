# 威胁模型：实时聆听 0.1

实时聆听会安装全局键盘和鼠标钩子，向其他应用合成输入，把声音发给网络服务，并保存识别服务的密钥。下面按规范模板 18.6 记录。

- **要保护的资产**
  - 用户说的话：录音、识别文字和保存在本机的随手记。
  - 用户的按键和点击（钩子能看到全部输入）。
  - 自定义识别服务的密钥。
  - 目标应用里的内容：错误的合成输入可能误删文字或误发消息。
- **入口**
  - 全局钩子收到的键盘和鼠标事件。
  - 识别服务进程的标准输出（豆包桥接或用户添加的程序）。
  - `%APPDATA%\LiveListen\settings.json`。
  - 界面经 `ll_call` 发来的命令（同一进程内）。
- **信任边界**
  - 应用进程与识别服务进程之间（JSON 行协议）。
  - 本机与网络服务之间（豆包服务器或用户添加的识别服务）。
  - 普通权限的应用与管理员权限窗口之间（Windows 的界面权限隔离）。
- **攻击者能做什么**
  - 控制网络服务或中间网络的人能返回任意文字。
  - 能写当前用户文件的程序能改设置、替换服务程序。（它本来就能以用户身份做任何事，不在本模型的防护范围。）
  - 旁人能看到屏幕上的浮条和字幕。

## 主要威胁

| 类别 | 威胁 | 对策 | 规则 |
| --- | --- | --- | --- |
| 篡改 | 服务返回的文字带控制字符或双向文本覆盖字符，写入后变成回车、退格或伪装显示 | 写入前去掉控制字符和双向覆盖字符；文字只作为输入内容，从不当作命令 | AI-01 |
| 篡改 | 听写中用户切到别的窗口，文字被写进错误的应用 | 前台窗口变化即暂停写入，未写入后缀自动转到剪贴板，浮条只显示复制结果状态 | GEN-09 |
| 信息泄露 | 在密码框中听写，密码以明文形式发给识别服务 | 用 UI 自动化和 `ES_PASSWORD` 检测密码框，拒绝听写并提示 | SEC-07 |
| 信息泄露 | 钩子收到的按键被记录下来 | 钩子回调只做快捷键匹配；日志只记事件、错误码和长度，不记文字和按键 | SEC-06 |
| 信息泄露 | 密钥进入设置文件、日志、命令行或界面 | 密钥存入 Windows 凭据管理器 `LiveListen/<名称>`；界面只能查询是否存在；自定义服务只通过指定的环境变量拿到自己的密钥 | SEC-06、SEC-07、SEC-09 |
| 信息泄露 | 用户不清楚声音和文字发给了谁 | README「数据去向」列出每类数据的去向；设置的服务页说明当前服务 | DOC-02 |
| 拒绝服务 | 钩子回调卡住，导致整台电脑输入变慢 | 回调只做匹配并排队，合成输入在回调返回后发送；结束听写时暂扣输入最多 3 秒。界面进程只在浮条右键菜单打开期间临时安装键盘和鼠标钩子，回调只查窗口并排队关闭，事件原样传下去，菜单关闭即卸载；设置页等改为异步调用引擎，界面线程不会长时间阻塞 | — |
| 拒绝服务 | 服务进程挂起或不停输出 | 检查服务有超时；进程退出后重新启动有间隔；空闲进程按时关闭 | — |
| 权限提升 | 借本应用向管理员窗口注入输入 | 本应用以普通权限运行，Windows 会拦截向管理员窗口的合成输入；检测到这种目标时直接提示，不尝试绕过 | — |
| 仿冒 | 设置里的自定义服务命令被换成别的程序 | 只运行用户填写的完整路径，或在 `PATH` 中查找该程序名（不查当前目录）；豆包桥接从程序目录向上查找固定的相对路径 | AI-04 |
| 篡改、拒绝服务 | 更新元数据提供任意下载地址、过大文件或损坏包 | 只读取固定 GitHub 仓库的正式发布；精确匹配版本、架构和包名；限制 HTTPS 源及重定向域名、响应大小和下载时间；核对资产 SHA-256 与长度后才公开文件；下载文件不自动执行 | SEC-06、GEN-09 |

## 残余风险（接受）

- 全局钩子本身要求本应用能看到全部按键，用户需要信任本应用。
- 豆包识别使用 `doubao_asr` 创建的网页访客会话，音频发往豆包服务器；它的数据处理遵循豆包的条款，本应用无法控制。
- 用户添加的识别服务程序以用户权限运行，应用不审查它的行为。
- 浮条、字幕和桌面卡片会显示文字，屏幕共享或旁人可见。字幕平时只在内存中保留最近几行；卡片可一键隐藏（`Ctrl+Alt+K`）。
- 本机保存的卡片没有加密，能读当前用户文件的程序都能读到。
- 程序和安装包未签名；更新检查会自动下载并校验包，但由用户启动安装。SHA-256 来自同一 GitHub 仓库，不能防御发布账号本身被入侵，也不能代替代码签名。
- 安装程序只为当前用户安装，不请求管理员权限；它按完整路径关闭本安装中的进程，只删除安装记录中的文件和指向本安装的开机启动项。卸载时临时文件夹中的副本会在原进程退出后删除 `Uninstall.exe`，副本只在安装记录已删除时动手。
