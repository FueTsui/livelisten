# 快捷键重做与验收（2026-11-08）

## 范围和实现

按用户提供的截图与 `hotkey_input.rs` 作为界面/交互参考，替换快捷键设置页。参考文件作为任务数据处理。保留本工作区已有卡片、编辑器和更新流程改动。本轮最终模块验证与交付记录见 [MODULE_AUDIT_20261108.md](MODULE_AUDIT_20261108.md)；没有推送、打标签或发布。

- 每行右侧使用带键盘图标的单一录入框，清除按钮位于框内。点击、按键、完全释放后校验并保存。
- 支持左右修饰键、功能键与组合键；Esc、失焦、离页、关闭和点击框外取消。
- 前台录入开始前等待底层钩子确认；捕获期间停用业务快捷键匹配，按键仍传给当前录入控件。会话 token 防止旧取消操作结束新录入；结束后有释放保护。
- 重复绑定不覆盖配置；保存失败保留候选值及重试入口，跨页保留。只有保存确认后显示成功。
- 冲突、保存失败和成功状态直接显示在当前快捷键的说明位置；快捷键保存失败不触发顶部黄色横幅，也不覆盖其他行已有的冲突原因。
- 默认随手记为 `RAlt`，独立按下并松开时触发。组合按键、AltGr、鼠标操作不作为独立轻按。schema 4 仅迁移无冲突的旧默认 `Ctrl+Alt+N`，保留其他自定义、禁用和 schema 4 下主动选回旧绑定的配置。
- 修复随手记页缓存的快捷键说明没有随设置变更刷新的问题。

## 数据保护与边界

原用户实例先正常退出，再备份设置和卡片并核对 SHA-256，备份位于 `target/hotkey-smoke-20261108/user-backup-20261108-221055`。故障注入仅修改独立测试文件属性，已恢复可写；未覆盖安装目录、未清空用户卡片、未读取凭据。

本轮没有进行麦克风/云转写端到端验收、物理键盘长按与多国际布局/真实 AltGr 验收，也未验证 Windows 保留组合键均可覆盖。录入与全局卡片匹配已分别实测，不能据此声称所有语音服务和所有键盘环境通过。
