# 实时聆听使用说明

| 操作 | 默认入口 |
| --- | --- |
| 按住说话 | 右Ctrl，松开结束 |
| 持续听写 | Ctrl+Alt+Space |
| 开关字幕 | Ctrl+Alt+C |
| 随手记 | 按住 Ctrl+Right，松开右方向键后结束并保存 |
| 持续记录 | Ctrl+Alt+N，或托盘菜单的「随手记」 |
| 新建空白随手记 | Ctrl+Alt+L，直接在桌面编辑 |
| 显示/隐藏卡片 | Ctrl+Alt+K |
| 显示/隐藏浮条 | 单击托盘图标 |
| 显示听写实时文字 | 托盘右键菜单「显示听写」或听写设置「浮条显示实时文字」 |
| 设置与退出 | 托盘或语音图形右键菜单 |

快捷键可自定义。在设置的快捷键页点击右侧带键盘图标的输入框，等待“请按快捷键”后按下新键或组合键，松开后保存；按 Esc、点击其他位置或切换窗口取消。输入框的清除按钮用于禁用该项，重复绑定会提示冲突，只有保存成功后才显示“已保存”。

随手记默认使用 Ctrl+Right，按下右方向键时开始录音，松开右方向键时结束。升级时，原默认键会迁移到 Ctrl+Right，若该组合已被占用则保留原绑定。自定义或禁用的绑定继续生效。托盘「随手记」保持原操作：点一次开始，再点或按普通键结束。三个随手记快捷键可单独设置。托盘会显示当前绑定的听写、字幕、持续记录和卡片快捷键；新增的默认键若已被自定义绑定占用，会留空供重新设置。持续听写时下一次按键或点击结束听写；可设置为只结束，或收尾后继续执行该操作。

## 听写和文字保护

先将光标放到目标输入框再开始。“稳定写入”只追加已确认文字；“实时修正”先写临时结果，随后可能退格修正。不同程序、输入法和权限级别需要实际确认。

切换目标、遇到密码框或无法写入时，程序会暂停或提示。未写入后缀会尝试复制到剪贴板，浮条只显示等待、成功或失败状态；请确认提示后再粘贴。剪贴板历史和同步由Windows管理。

## 图形、字幕与卡片

在外观设置选择星云或星河；滚轮调整大小，拖动图形改变位置。两种样式分别保存尺寸。文字通常显示在下方，底部空间不足时转到上方。

听写文字外观统一设置字号、文字/背景/轮廓颜色及透明度、圆角、内边距、阴影和图形文字间距。纯白/纯黑柔化显示，保留透明度；其他自定义颜色保持。字幕和卡片有独立外观。

字幕可选电脑声音、麦克风或混合；字号、行数和占屏宽度可调，只在内存保留最近内容。随手记保存为卡片，支持编辑、完成、归档、隐藏、改日期和单张外观。删除卡片不可恢复。

桌面卡片的归档、从桌面隐藏按钮只在鼠标悬停标题栏时显示，移开即隐藏。待办勾选框与随手记图标均为 14 DIP，保留标题行的点击高度。

右键标题栏可从“配色”选择纸白、浅黄、浅紫、浅粉、薄荷或浅蓝，也可选“默认（跟随统一外观）”。预设只改变该卡片的颜色，圆角、边距和阴影保持原值。默认文字色随背景深浅使用柔白或柔黑，手动设置的文字颜色保留。标题栏菜单不再提供“归档”“自定义外观”和“修改日期和时间”，双击标题栏也不再打开日期选择器；归档仍可用悬停时出现的标题栏按钮。

点击桌面卡片正文开始编辑，底部显示加粗、倾斜、下划线、删除线、链接和列表工具。在设置的随手记列表中，聚焦正文即可编辑。列表提供项目符号、短划线、编号和无列表。独立待办卡片通过标题栏勾选完成。链接弹窗可以输入地址和显示文字，也可以先选中文字再添加链接。按 Esc 或离开编辑区域收起工具栏。格式随卡片保存并在重启后恢复。新建或编辑超出 4000 字时保留草稿并提示精简，富文本还受格式大小限制。

在“设置 → 外观 → 桌面卡片”的“调整对象”下设置“标题信息”：无、年月日、月日、月日-时:分、月日-星期、月日-标题、星期-标题、标题。默认选中“标题”，已有的标题信息选择会保留。相关模式可选择显示日期或填写自定义标题；留空标题使用随手记或待办名称。日期只影响标题显示，原记录日期和 Markdown 归档日期不变；“无”隐藏标题文字，仍可拖动和打开标题菜单。

在随手记页点击“打开记录文件夹”，可查看 `%APPDATA%\LiveListen\随手记` 下的“进行中 / 已完成 / 已归档”三个文件夹。每个文件夹按卡片日期生成 `YYYY-MM-DD.md`，同一天的记录放在一起，包含类型、时间、完成状态和正文；归档优先于完成状态。完成、归档、恢复、改日期或删除后自动同步，单纯从桌面隐藏不改变归类。

Markdown 是便于阅读和备份的单向文本记录，完整富文本仍保存在 `cards.json`。请在应用中编辑卡片；手动改过的 Markdown 不会被覆盖，会显示同步失败并保留原文件。关闭程序后可先将该文件另存到其他位置，再启动让应用重建日期记录。自定义测试数据目录时，记录文件夹也跟随该目录。

应用运行时默认每天检查一次，有新版会提醒。点击“设置 → 通用 → 检查更新”才开始下载。安装版校验通过后自动替换并重启，便携版可打开下载位置解压 ZIP。可在通用设置关闭每日检查。

## 识别服务

| 服务 | 配置要点 |
| --- | --- |
| 内置豆包兼容通道 | 包内有模块和依赖；网页访客服务变化时可能不可用 |
| 豆包官方 | 对应服务的应用、资源和凭据 |
| OpenAI | 有效API凭据与实时转写模型权限 |
| 千问 | 对应地域、模型和有效API凭据 |
| 腾讯 | 对应应用、SecretId/SecretKey与引擎配置 |

从“服务 → 添加”配置；已添加服务可右键编辑。密钥保存在Windows凭据管理器，不回显旧值；不要将密钥填进URL或名称。服务检查不验证真实云鉴权、地域、配额或识别质量。

提前连接在“听写”设置中选择档位，只准备接口，开始听写才采集音频：

| 档位 | 行为 |
| --- | --- |
| 关闭（默认） | 开始听写时才连接 |
| 均衡 | 每次听写后的 2 分钟内保持一个就绪连接；按住听写键时也会立即开始连接 |
| 积极 | 启动后和每次听写后的 10 分钟内保持就绪；首字最快，连接识别服务的次数最多 |

离开电脑（含锁屏）超过均衡档 1 分钟、积极档 3 分钟后暂停准备，回来后有输入即恢复。关闭或切换服务会释放未使用的连接，活动会话结束后使用新选择。音频发给当前所选服务，账号条件及数据政策由服务商提供。

## 常见情况

- 没有声音：检查所选麦克风和Windows权限，先在系统设置确认设备。
- 文字未写入：检查目标输入框及权限，查看暂停或剪贴板状态。
- 服务不可用：核对网络、接口、地域、凭据和额度；本地检查成功不代表云端可用。
- 关闭浮条后仍运行：这是托盘行为，选择“退出”结束。
- 保存失败：先处理提示，不强制结束进程；程序会保留修改并重试。
