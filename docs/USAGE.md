# 实时聆听使用说明

| 操作 | 默认入口 |
| --- | --- |
| 按住说话 | 右Ctrl，松开结束 |
| 持续听写 | Ctrl+Alt+Space |
| 开关字幕 | Ctrl+Alt+C |
| 语音随手记 | Ctrl+Alt+N |
| 显示/隐藏卡片 | Ctrl+Alt+K |
| 显示/隐藏浮条 | 单击托盘图标 |
| 显示听写实时文字 | 托盘右键菜单「显示听写」或听写设置「浮条显示实时文字」 |
| 设置与退出 | 托盘或语音图形右键菜单 |

快捷键可自定义。持续听写时下一次按键或点击结束听写；可设置为只结束，或收尾后继续执行该操作。

## 听写和文字保护

先将光标放到目标输入框再开始。“稳定写入”只追加已确认文字；“实时修正”先写临时结果，随后可能退格修正。不同程序、输入法和权限级别需要实际确认。

切换目标、遇到密码框或无法写入时，程序会暂停或提示。未写入后缀会尝试复制到剪贴板，浮条只显示等待、成功或失败状态；请确认提示后再粘贴。剪贴板历史和同步由Windows管理。

## 图形、字幕与卡片

在外观设置选择星云或星河；滚轮调整大小，拖动图形改变位置。两种样式分别保存尺寸。文字通常显示在下方，底部空间不足时转到上方。

听写文字外观统一设置字号、文字/背景/轮廓颜色及透明度、圆角、内边距、阴影和图形文字间距。纯白/纯黑柔化显示，保留透明度；其他自定义颜色保持。字幕和卡片有独立外观。

字幕可选电脑声音、麦克风或混合；字号、行数和占屏宽度可调，只在内存保留最近内容。随手记保存为卡片，支持编辑、完成、归档、隐藏、改日期和单张外观。删除卡片不可恢复。

## 识别服务

| 服务 | 配置要点 |
| --- | --- |
| 内置豆包兼容通道 | 包内有模块和依赖；网页访客服务变化时可能不可用 |
| 豆包官方 | 对应服务的应用、资源和凭据 |
| OpenAI | 有效API凭据与实时转写模型权限 |
| 千问 | 对应地域、模型和有效API凭据 |
| 腾讯 | 对应应用、SecretId/SecretKey与引擎配置 |

从“服务 → 添加”配置；已添加服务可右键编辑。密钥保存在Windows凭据管理器，不回显旧值；不要将密钥填进URL或名称。服务检查不验证真实云鉴权、地域、配额或识别质量。

提前连接在“听写”设置中选择档位，只准备接口，开始听写才采集音频：

| 档位 | 行为 |
| --- | --- |
| 关闭（默认） | 开始听写时才连接 |
| 均衡 | 每次听写后的 2 分钟内保持一个就绪连接；按住听写键时也会立即开始连接 |
| 积极 | 启动后和每次听写后的 10 分钟内保持就绪；首字最快，连接识别服务的次数最多 |

离开电脑（含锁屏）超过均衡档 1 分钟、积极档 3 分钟后暂停准备，回来后有输入即恢复。关闭或切换服务会释放未使用的连接，活动会话结束后使用新选择。音频发给当前所选服务，账号条件及数据政策由服务商提供。

## 常见情况

- 没有声音：检查所选麦克风和Windows权限，先在系统设置确认设备。
- 文字未写入：检查目标输入框及权限，查看暂停或剪贴板状态。
- 服务不可用：核对网络、接口、地域、凭据和额度；本地检查成功不代表云端可用。
- 关闭浮条后仍运行：这是托盘行为，选择“退出”结束。
- 保存失败：先处理提示，不强制结束进程；程序会保留修改并重试。
