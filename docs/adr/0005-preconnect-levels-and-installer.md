# 0005 提前连接档位与自带安装程序

- 日期：2026-11-08
- 状态：采用

## 背景

需要提供提前连接档位，让用户在首字等待时间和连接频率之间选择。除便携 ZIP 外，也提供支持升级与卸载的 Windows 安装包。

## 决定

- **提前连接三档，默认关闭。** 设置字段 `dictation.preconnectLevel`：`off` 只在开始听写时连接；`balanced` 启动时不准备，每次听写或按住听写键后保持 2 分钟，无输入 1 分钟后停止续期；`aggressive` 启动后和每次听写后保持 10 分钟，无输入 3 分钟后停止续期（即原来开关打开时的行为）。设置结构升到版本 3：版本 2 的开关为开时迁移为 `aggressive`。旧字段只读不写，较旧版本的程序读到新设置时提前连接视为关闭，不会因未知值拒绝整个设置。
- **安装程序是本仓库的 `setup` crate。** 一个可执行文件兼任安装程序和卸载程序：程序文件压缩后追加在后面，整体 SHA-256 在写入任何文件前校验。产品名称、快捷方式、数据目录、凭据前缀和退出参数都来自 `setup/install-manifest.json`，代码不含产品专有文字（REL-08 的共享方向）。
- **界面与 SightOCR 安装包一致。** 使用相同版本的 egui / eframe（0.31.1，glow），640×460 固定窗口：欢迎页只有「立即安装」，「自定义选项」可改位置、快捷方式、开机启动和安装后运行；已安装时右下角提供「卸载 vX」；进度页、结果页、深浅色跟随系统。窗口无法创建时退回系统对话框并按默认选项安装。静默参数与退出码按 REL-04。
- **每个文件单独暂存与回滚。** 新文件先解压到安装目录内的 `.setup-<pid>\new`，替换时把旧文件移到 `.setup-<pid>\old`；任一步失败就把每个文件移回原处并恢复注册信息。快捷方式和开机启动在提交后设置，失败只作为提示，不回滚已完成的替换。
- **按完整路径关闭程序。** 先用 `--quit` 请它保存后退出，交互模式 15 秒后结束；`/UPDATE` 最多等 120 秒且从不强制，超时返回 7。其他文件夹中同名的程序不受影响（REL-03）。
- **只为当前用户安装，不请求管理员权限。** 默认安装到 `%LOCALAPPDATA%\Programs\LiveListen`，只写当前用户的开始菜单和 `HKCU` 注册表项。这与规范 8.4“安装需要 UAC”不同，登记为例外：程序与数据都只属于当前用户，提升权限不带来好处，反而让安装后自动启动的程序继承管理员令牌的风险需要额外处理。
- **静默安装不启动程序。** 与 SightOCR 相同：`/SILENT`、`/VERYSILENT` 完成后不启动，`/UPDATE` 只在升级前程序正在运行时重新启动它。
- **卸载程序自删除。** 从安装目录运行时，把自身复制到临时文件夹，由副本等待原进程退出后删除 `Uninstall.exe` 和空目录，再由 cmd 删除副本。副本只在临时文件夹中、且安装记录已删除时才动手。
- **README 按 SightOCR 的版式重写。** 居中标题、徽标与链接行、表格化的功能与快捷键、折叠的构建说明；同时保留规范要求的“接口”“平台级别”“规范例外”章节。历史留在 CHANGELOG，不放进 README（DOC-01）。

## 后果

- 默认关闭，仅在听写开始时建立连接。均衡或积极模式可缩短首字等待时间。
- 安装程序引入 egui、glow 等约 110 个 Rust 组件。它们只链接进 `setup.exe` / `Uninstall.exe`，但许可文本都要随包提供；其中 12 个组件的发布包没有附许可文本，固定副本放在 `third_party/licenses/` 并在打包时校验 SHA-256。
- 安装窗口依赖 OpenGL。没有可用驱动的远程桌面或虚拟机会退回系统对话框，只能按默认选项安装。
- 安装程序仍留在本仓库，尚未拆成与 SightOCR 共享的 crate，登记为 REL-08 例外；两边的参数、退出码和界面约定保持一致，便于以后合并。
- 程序未签名（REL-10、REL-21 例外不变），首次运行可能出现 SmartScreen 提示。
- 隔离测试模式只在调试版生效（`SETUP_TEST_ROOT`，REL-06）：安装位置、开始菜单、AppData 和注册表都改到测试文件夹，注册表写入 `registry.json`；发布版不包含该变量名。
